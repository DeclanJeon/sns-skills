# 한국 AI 드라마·사연 유튜브 썸네일

근거: `/home/declan/Documents/Projects/Products/04_Skills/Skills-and-Automation/SNS/data/youtube-kr/youtube_korean_collection_300.csv` (한국 영상 300개, 썸네일 `yt_thumbs/`). 아래 패턴은 상위 AI 드라마 썸네일 육안 분석 결과이며 **상관관계지 인과가 아니다**. 조회수에는 채널 규모·시리즈 누적·알고리즘이 섞인다.

## 구조 (1순위 → 3순위)

1. **인물/피사체 1개를 크게 (프레임의 40~60%)**: 감정이 읽히는 얼굴 클로즈업, 또는 행동 중인 몸(발차기, 칼, 멱살). 군중은 배경으로만.
2. **2줄 대형 문구, 하단 또는 한쪽 면**: 윗줄은 상황(흰색/노랑), 아랫줄은 결과·감정어(강조색). 줄당 4~9자, 전체 8~16자.
3. **배지 1~2개**: 회차(`3화`, `EP.1` 우상단), `1~9화 몰아보기`, `AI 단편 영화`(하단 작은 라벨), 성과(`100만뷰`, `누적 조회수 400만` 금메달/월계관).

## 문구 패턴 (실제 상위 예)

| 패턴 | 예 |
|---|---|
| 신분 반전 | `청소부 아줌마가 회장님이었다` |
| 응징 예고 | `조폭들의 최후`, `참교육`, `고딩들이 사람을 잘못 건드렸다` |
| 상황+결과 미완 | `연기하랬더니 진짜가 왔다`, `장군이 하루 벌었더니…` |
| 충돌/대결 | `고대 장군 VS 프로 격투기 선수` |
| 설정 한 줄 | `좀비로 세상 망했는데 나 혼자 풀옵션 벙커` |
| 호기심 질문 | `아직도 안본사람 있어?` |
| 인용 대사 | `"쫓아낼 땐 언제고 다시 와?"` |

규칙: 제목과 **같은 문장을 반복하지 않는다**. 썸네일은 장면/감정, 제목은 서사/설정을 맡는다.

## 디자인

- **색**: 어두운 시네마틱 배경(남색·검정·붉은 조명) + 흰 글자 + 강조 1색(노랑 또는 빨강). 강조색은 한 줄 또는 핵심 단어 하나에만.
- **글꼴**: 굵은 고딕/헤비 계열, 두꺼운 외곽선+그림자. 사극/로맨스 장르만 붓·명조 계열 타이틀 로고 허용.
- **정보 위계**: 시선 순서 = 얼굴/행동 → 강조 문구 → 회차 배지 → 작은 라벨. 라벨은 크기 최소화.
- **시리즈 통일**: 같은 시리즈는 구도·폰트·회차 위치를 고정하고 인물/장면/문구만 교체 (`장군님 출근하십니다` 계열이 대표).
- **AI 이미지 주의**: 손·눈·글자 깨짐을 확인. 한글 문구는 이미지 생성 모델에 맡기지 말고 후처리로 얹는다.

## 모바일 검수 (필수)

작게(약 168×94px) 줄여서 확인: ① 인물과 감정이 보이는가 ② 문구가 읽히는가 ③ 한 번에 이야기가 상상되는가 ④ 문구 16자 이하인가 ⑤ 배지가 얼굴을 가리지 않는가.

## 하지 말 것

- 영상에 없는 장면·인물·수상·`100만뷰` 배지 표기 (성과 배지는 실제 수치만).
- 글자 5줄 이상, 강조색 3개 이상, 얼굴 3개 이상 동급 배치.
- 설정 설명만 있고 감정·갈등이 없는 문구(`AI 제작 단편 영화`만 크게 쓰는 경우는 SF/전쟁 대형 타이틀 장르에서만, 조회수 우위는 확인되지 않음).

## 산출 형식

요청 시 아래를 낸다: 구도 설명 / 문구 2줄(+대안 3개) / 배지 / 색 팔레트 / 이미지 생성 프롬프트 / 모바일 검수 결과. 변형 A/B는 **하나의 변수만** 바꾼다(얼굴 vs 행동, 문구 어순 등).
