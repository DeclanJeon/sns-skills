# 한국 AI 드라마·사연 후킹

범위: **패키지 훅**은 표본 300개의 썸네일·제목 분석, **도입부 시작 방식**은 자막 73개 분석에서 도출. 시청 유지율 데이터가 없어 도입부 효과 크기는 검증되지 않았다. 채널 분석 데이터(YouTube Studio 유지율)로 검증해 갱신한다.

## 1. 코어 훅 한 문장 먼저

모든 요소의 기준: `누가 + 무엇을 당해/겪어 + 곧 무엇이 뒤집힌다` 한 문장.
예: 청소부를 무시한 팀장 → 그 청소부가 회장.
이 문장이 안 만들어지면 제목·썸네일을 만들지 않는다.

## 2. 표본에서 반복된 훅 유형

| 유형 | 감정 엔진 | 표본 예 |
|---|---|---|
| 신분 반전 | 통쾌·궁금 | 청소부 아줌마가 회장님이었다 |
| 응징·참교육 | 카타르시스 | 조폭들의 최후 |
| 시간/세계 충돌 | 신기함 | 장군님 출근하십니다, 타임슬립 1950 |
| 한 줄 설정 | 호기심 | 좀비 세상 나 혼자 풀옵션 벙커 |
| 가해자의 몰락 | 복수 쾌감 | 쫓아낸 여자들은 모른다… 밤마다 구걸했다 |
| 대결 | 승부 궁금 | 고대 장군 VS 프로 격투기 선수 |
| 사연/눈물 | 공감·연민 | 버스기사 찾아온 학생의 사연 |

시리즈는 **같은 훅 엔진을 매 화 교체 소재로 반복**할 때 누적 조회(몰아보기)가 커졌다 (`장군님 출근하십니다` 등).

## 3. 정합성 3점 (제목·썸네일·도입부)

- 썸네일: 장면과 감정, 제목: 설정과 갈등, 도입부: **15초 안에 두 약속의 첫 장면 제시**.
- 약속한 장면은 영상 앞 30초 안에 최소 한 번 보여준다(시청자가 속았다고 느끼면 이탈).
- 약속의 **완결**(응징·정체 공개)은 영상 끝까지 아껴 두되, 중간 확인 장면을 1회 이상 준다.

## 4. 도입부 15초 구조

자막 73개 근거(`kr-yt-script-structure`): 첫 대사 시작 중앙값 2초, 39/73이 3초 이내. 상위 에피소드는 인사·로고 없이 **갈등 대사 한 줄**로 시작(`고아원 출신이 어디감 가족 자리에 앉아`, `어이 아가씨 이거 왜 이렇게 비싸? 깎아 줘 좀`). 아래 1은 이 근거, 2~4는 원칙.

1. 0~3초: 갈등 대사/장면부터 시작, 로고·인사·설명 금지.
2. 3~10초: 상황 한 줄 + 피해/위기 시각화.
3. 10~15초: "곧 뒤집힌다" 신호(대사·표정·소품) 후 본 이야기로.
4. 몰아보기는 중간 챕터마다 소(小) 클리프행어 재배치(2~4분 간격 권장, 검증 필요).

## 5. 엔딩 훅

- 에피소드: 다음 화 갈등을 **질문 상태로** 끊는다. 다음 화 제목·썸네일 예고를 고정 위치에.
- 단편: 마지막 반전 후 짧은 여운. 댓글 질문 하나만 유도.

## 하지 말 것

- 과장된 약속 후 미이행, 거짓 `실화`, 실존 인물·사건 왜곡, AI 제작 표시 은폐.
- 한 영상에 훅 유형 3개 이상 혼합.

## 산출 형식

코어 한 문장 / 훅 유형 / 제목 3안 / 썸네일 문구 3안 / 도입부 15초 비트 / 엔딩 훅 / 검증 지표 (노출 클릭률, 평균 시청 지속, 30초 유지율).
