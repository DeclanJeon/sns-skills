# X 팔로워 성장 플레이북

팔로워 숫자 자체보다 타깃 독자가 계정을 발견하고, 팔로우할 이유를 확인하고, 다음 게시물을 기대하게 만드는 데 초점을 맞춘다.

1. **기준선:** 제공된 계정의 주제, 타깃, 목표, 운영 가능 시간과 최근 지표를 사용한다. 빠진 지표는 미확인으로 표시하고, 계획을 바꿀 핵심 정보만 질문한다. 새 계정도 데이터 없이 출발 계획을 받을 수 있다.
2. **우선순위 3개:** [전략과 출처](references/youtube-growth-strategies.md)를 읽고 병목을 고른다. 발견이 적으면 관련 대화와 첫 줄, 방문 대비 팔로우가 적으면 소개와 고정 글, 꾸준히 읽힐 이유가 약하면 반복 가능한 연재를 먼저 본다. 데이터가 없으면 병목은 가설이다.
3. **4주 실험:** 1주 차에 기준선을 적고 프로필·고정 글을 정리한다. 2주 차에는 유지 가능한 발행과 답글 루틴을 시작한다. 3주 차에는 한 가지 변수만 바꿔 유사한 글끼리 비교한다. 4주 차에 유지·수정·중단할 것을 정한다. 사용자 일정에 맞춰 빈도를 조정하고 각 우선순위에 이번 주 행동을 하나씩 붙인다.
4. **측정:** 가능하면 순 팔로워 증가, 프로필 방문, 게시물 노출을 같은 기간으로 비교한다. 게시물별 팔로우 귀속을 확인할 수 없으면 계정 단위 변화로만 기록한다. 분석 데이터가 없다면 주간 팔로워 수와 어떤 실험을 했는지만 기록하고, 인과나 정확한 전환율을 단정하지 않는다.

최신 사례가 요청되면 `flucto-media-research`를 사용한다. 현재 CLI 도움말을 확인한 뒤 지원되는 `flucto search "<검색어>" --platform youtube --limit 10 --json`으로 후보를 찾는다. 게시일과 확인 수준은 별도로 검증하고, 최신 자료 확인에 실패하면 기존 노트의 조사 시점과 한계를 표시한다. 과거 영상의 횟수·시간대·성장 속도·알고리즘 주장은 플랫폼 규칙이나 보장으로 제시하지 않는다.

이 스킬은 전략과 실험 설계용이다. 게시·답글 전송·팔로우·DM을 실행하지 않는다. 팔로워 구매, 품앗이, 대량 자동화 대신 실제 관심사가 겹치는 독자와의 대화를 제안한다. 한서윤 계정의 답글 문안 자체가 요청되면 `han-seoyun-x-replies`를 사용한다.
