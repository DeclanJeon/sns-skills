# 유튜브 성장 운영 지침서

**한 문장:** 같은 시청자가 다시 보고 싶은 영상을 만들고, 게시 결과로 다음 편의 가장 중요한 한 가지를 바꾼다.

이 문서는 쇼츠·롱폼의 채널 운영과 기존 영상 진단에 쓴다. 새 성장 기회를 찾는 요청은 [시장 진입 절차](market-entry.md)에서 조사와 수요 검증을 먼저 하고, 아래 채널 방향·제작·측정 절차로 연결한다. 이 문서는 운영의 기본값이지 알고리즘의 공식 배점표가 아니다. 근거와 한계는 [성장 근거표](성장-근거표.md), 전체 자료는 선택적 [원본 아카이브의 영상 인덱스](/run/media/declan/Data/아카이브/유튜브-성장-알고리즘.sJH7ua/영상-인덱스.jsonl)에 있다.

## 1. 채널 방향: 어떤 사람이 왜 다시 보는가

- **신규 채널:** `나는 [구체적인 시청자]가 [상황/문제]에서 [결과]를 얻는 영상을 만든다.` 같은 사람의 서로 다른 질문에 답하는 시리즈 후보 2개를 적는다. 첫 주에는 제작 여력으로 다음 편을 낼 수 있는 시리즈 1개부터 선택한다.
- **기존 채널:** 최근 잘된 영상을 조회 순서대로 복제하지 말고 `누가, 어떤 순간에, 어떤 답을 얻으러 왔는지`로 묶는다. 제목과 소재가 달라도 같은 시청 의도가 있으면 시리즈 후보로 본다.
- **판정:** 첫 편을 설명했을 때 같은 사람이 볼 다음 편 두 개가 떠오르는가? 떠오르지 않으면 주제나 시청자 범위를 좁힌다. **근거: E01, E02, E06.**

## 2. 소재 발굴: 다음 편을 고른다

1. 같은 시청자의 질문 3개를 적는다. 내 채널 검색어·댓글·유입 영상이 있으면 우선한다. 없다면 관련 검색어와 비슷한 포맷의 채널에서 실제 날짜와 링크가 있는 탐색 자료를 모은다.
2. 각 질문에 `수요 단서 / 채널의 약속에 맞는가 / 실제로 보여줄 증거와 제작 여력`을 적는다. 단서는 후보 선택에 쓰고, 성과를 예측하지 않는다. 날짜·포맷·채널 규모가 다른 공개 조회수는 단순 순위로 쓰지 않는다.
3. 제작 가능한 한 편을 고르고, 출처나 수요를 못 확인한 소재는 `가설`로 표시한다. 실제 소재 발굴·순위가 요청된 경우 별도의 소재 수요 평가 절차를 사용한다. **근거: E01, E07.**

## 3. 영상 설계: 클릭 또는 시청 선택과 실제 보상을 맞춘다

| | 쇼츠 | 롱폼 |
|---|---|---|
| **첫 선택** | 첫 화면만 봐도 상황이나 질문을 이해하도록 구성. 시작부터 설명이 필요하다면 설명 전에 구체적인 결과·행동을 보여준다. | 촬영 전에 제목·썸네일 후보를 만든다. 같은 약속을 두 번 쓰기보다 서로 보완하게 하되, 증거보다 큰 약속은 피한다. |
| **계속 볼 이유** | 질문 → 진행/증거 → 보상. 이야기 진행에 필요한 길이를 쓰고, 기다리는 구간을 줄인다. | 초반에 제목이 약속한 문제·결과를 확인시킨다. 각 구간이 새 답이나 근거를 주는지 살핀다. |
| **다음 시청** | 단독으로 완결하되, 관련 후속 질문이 있으면 다음 편이나 연결 영상으로 이어준다. | 관련 후속편이 실제로 같은 문제를 이어받을 때만 안내한다. |

한 영상으로 모든 것을 시험하지 않는다. 이번 편이 **소재**, **첫 장면/패키징**, **본편 흐름**, **후속편 연결** 중 무엇을 검증할지 한 줄로 남긴다. “첫 3초”, “40초 이상”을 보편 규칙으로 적용하지 않는다. **근거: E03, E05, E08, E09, E10.**

## 4. 게시·측정: 같은 조건에서 비교한다

- 게시 전 `목표 / 주 가설 / 이번에 바꾼 한 가지 / 주 지표 / 볼 기간 / 비교군`을 기록한다. 예: 같은 시리즈와 길이대의 롱폼, 게시 후 첫 7일. 7일은 예시이며 어떤 일수도 최적이라고 가정하지 않는다.
- 주 지표와 가드레일을 나눈다. 예: 롱폼은 CTR(주)과 초반 유지율(가드레일). 쇼츠는 시청 선택 비율(주)과 평균 시청 비율(가드레일). 표본이 작거나 유입 구성·집계 정의가 달라지면 판정을 보류한다.
- **쇼츠:** 공개 조회, 유효 조회, 시청 선택/넘김, 평균 시청 시간(초)과 평균 시청 비율(%), 영상별 구독자 획득을 구분한다. 공개 조회 정의 변경 전후를 한 추세로 해석하지 않는다.
- **롱폼:** 노출과 노출 CTR은 가능한 한 같은 유입경로에서 비교한다. CTR이 모든 재생을 대표하지 않으므로 초반 유지율, 평균 시청 시간과 유입경로를 함께 본다. 지원되는 Studio 실험이 있으면 실험 조건과 결과 기준을 그대로 기록한다.
- **공통:** 조회는 도달의 일부, 영상별 구독 획득은 전환 단서, 채널 재방문은 전체 운영의 결과 단서다. 절대 구독자 수로 이 셋을 대신하지 않는다. **근거: E03–E06, E08, E12.**

## 5. 다음 편 결정: 유지·수정·보류

| 관찰 | 다음 행동 | 성급한 결론 |
|---|---|---|
| 쇼츠에서 시청 선택이 낮고 시청 후 유지가 비교적 안정적 | 같은 질문·비슷한 길이에서 첫 화면이나 첫 문장 하나를 바꾼다. | 알고리즘이 내 채널을 막았다. |
| 쇼츠 선택은 괜찮으나 특정 구간에서 이탈 | 그 구간의 반복 설명 또는 보상까지 기다리는 구간을 줄인다. 변경 전후 유지율을 같은 길이대로 비교한다. | 무조건 쇼츠 전체를 짧게 만든다. |
| 롱폼 노출 CTR이 낮고 클릭 후 유지율은 비슷 | 유입경로·비교 창을 확인하고 제목 또는 썸네일 한 요소를 시험한다. | CTR 숫자 하나로 썸네일 탓을 확정한다. |
| 롱폼 CTR은 높고 초반 이탈이 큼 | 제목·썸네일의 약속을 본편이 언제 보여주는지 확인한다. 문제와 결과를 더 일찍 보여주는 버전을 검증한다. | 썸네일이 성공했으니 더 강한 문구를 쓴다. |
| 공개 조회만 증가하고 유효 조회나 구독 획득은 미상 | 정의와 같은 기간의 유효 조회·영상별 구독 획득부터 확인한다. | 조회가 늘었으니 팬도 늘었다. |
| 시청은 늘고 구독 획득이 아직 정체 | 유입 시청자가 관심을 가질 후속 질문으로 다음 편을 만든다. 시리즈 약속을 더 분명히 하는 가설을 시험한다. | 무조건 구독 요청 횟수를 늘린다. |

정체기에는 데이터가 비어 있는 경로를 먼저 찾는다. 노출 부족·시청 시작 부진·시청 이탈·후속 시청 부진은 서로 다른 문제다. 집계가 부족하면 원인을 확정하지 말고 다음 게시에서 하나를 관찰한다. **근거: E03–E06, E08–E13.**

## 6. 시리즈 확장과 주간 운영

- **시작:** 이번 주 만들 수 있는 편수만 약속한다. 시간이 빠듯하면 두 포맷에 나누지 말고 핵심 편 하나를 먼저 완성한다. 초기 지표는 채널 기준선을 쌓는 데 쓴다.
- **운영 중:** 주초에 소재와 가설을 선택 → 제작·게시 → 설정한 관찰 기간이 끝난 콘텐츠만 복기한다. 이번 주 성과가 없더라도 같은 목표의 다음 편을 준비한다.
- **잘된 편:** 조회 자체보다 같은 시청자가 이어서 묻는 질문을 찾는다. 비슷한 조건의 여러 편에서 반복되면 제작 시간을 더 배정한다. 쇼츠의 시청자가 롱폼에도 관심을 보인다는 근거가 있을 때 두 포맷을 연결한다.
- **안 된 편:** 다음 편에서 가장 큰 병목 하나만 변경한다. 데이터가 누적되어도 개선 신호가 없고 제작비가 크면 보류한다. **근거: E01, E05, E06, E12.**

### 복사해서 쓰는 주간 운영 카드

```text
이번 주 시청자 / 채널의 약속:
주 목표 / 제작 가능 시간:
후보 세 가지와 수요 단서:
선택한 영상 / 포맷 / 첫 화면 또는 제목·썸네일 약속:
다음 편까지 배울 가설 하나 / 이번에 바꿀 변수:
주 지표 / 악화되면 안 되는 지표 / 비교군 / 게시 후 비교 창:
결과 / 남은 불확실성:
유지 / 수정 / 보류 / 다음 편:
```

여기서 제안하는 기준선·비교 창·한 변수 변경은 운영 실험의 기본값이다. 유튜브 공식 정책, 조회 보장, 검증된 인과관계로 인용하지 않는다.
