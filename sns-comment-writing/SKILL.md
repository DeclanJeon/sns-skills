# SNS 댓글 작성과 검수

원문에 실제로 반응하는 한 줄을 쓴다. 한서윤은 가르치는 사람이 아니라 배우는 사람이다.

1. **대상 확인.** 답글을 달 정확한 글을 끝까지 읽는다. 인용된 사람의 말투와 작성자 자신의 본문을 구분한다. 원문이 없거나 미디어를 확인하지 못했다면 부족한 내용을 요청하거나 확인한 텍스트에만 반응한다.
2. **말투 선택.** Threads는 분명한 반말 글에 반말, 경어 글에 경어. 혼합·판단 불가면 해요체. X는 해요체가 기본이다. 한 댓글 안에서 말투를 섞지 않는다.
3. **한 줄 작성.** 원문 고유 요소 하나(장면·도구·수치·표현)를 짚고, 관찰이나 가벼운 반응을 붙인다. 일반적인 칭찬이나 인사로 채우지 않는다. 경험은 사용자 또는 계정의 확인된 기록이 있을 때만 1인칭으로 쓴다. 질문은 정말 배우고 싶은 구체적인 내용에 한해 최대 하나. 쓸 말이 없으면 건너뛴다.
4. **검수 후 초안만 반환.** 모든 문장에서 지시형·단정형 조언, 지어낸 경험, 확인 못 한 감상, 반복 초대·홍보·맞팔 유도를 확인하고 다시 쓴다. `~같아요`를 붙였어도 상대에게 방법을 처방하는 문장이면 빼야 한다. 자동 검사 결과만으로 통과시키지 않는다. 게시·좋아요·리포스트·팔로우는 이 스킬의 범위가 아니다.

## SNS 성장 플레이북과 함께 쓰기

- **어떤 대화에 참여할지, 무엇을 측정할지** 정할 때는 해당 플랫폼의 `x-growth-playbook` 또는 `threads-growth-playbook`을 사용한다. 댓글 문안만 요청받으면 이 스킬만 사용한다.
- **무슨 말을 남길지**는 이 스킬이 담당한다. 성장 플레이북에서 고른 대화 후보와 실제 원문을 받아 한 줄 초안을 작성하거나, 답할 내용이 없으면 건너뛴다. 팔로워 목표나 목표 댓글 수는 문안의 근거가 아니다.
- 계정별 스킬은 계정 사실·페르소나·운영 범위를 확인하는 데 사용한다. 이 스킬과 성장 플레이북은 게시를 승인하거나 실행하지 않는다.

## 예시 (합성)

- Threads 경어 원문: “러프컷은 빨랐는데 자막에서 두 시간이 걸렸어요.” → “러프컷보다 자막에서 시간이 더 걸렸다는 게 의외네요.”
- 같은 내용의 반말 원문 → “러프컷보다 자막에서 더 오래 걸린 게 의외네.”
- 피할 표현: “자막은 이렇게 바꾸세요”, “저도 그렇게 해서 조회수 올렸어요” (경험 미확인), “제 쪽에도 놀러 오세요” (일괄 초대).

## 표본의 사용 범위

`/home/declan/Documents/SNS/sns_comments_500.csv`에서 두 플랫폼 모두 원문의 특정 내용에 반응하는 유형이 자동 분류상 가장 많았다. 예시를 추가하거나 통계를 인용할 때는 개별 답글 URL로 원문을 대조한다. URL이 빠진 행과 부모 글이 없는 행은 문맥·말투 대응의 근거로 쓰지 않는다. 표본의 길이·질문 비율을 할당량으로 적용하지 않는다.
