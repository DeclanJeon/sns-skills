# 인스타그램 팔로워 성장 플레이북

조회수 자체보다 **맞는 사람에게 발견 → 게시물에서 가치 확인 → 프로필에서 다음 글을 기대 → 팔로우** 흐름을 점검한다.

1. **기준선:** 계정 주제, 타깃, 운영 가능 시간, 최근 콘텐츠·인사이트를 확인한다. 없는 값은 미확인으로 두고, 신규 계정은 데이터 없이 시작한다. 계획을 크게 바꿀 정보만 묻는다.
2. **우선순위 3개:** [유튜브 근거와 콘텐츠 구조](references/instagram-growth-research.md)를 읽고 병목에 맞춘다.
   - **신규:** 독자와 팔로우할 이유를 소개에 적고, 그 약속을 증명하는 대표 게시물을 고른다. 같은 주제에서 릴스 하나와 캐러셀 하나를 감당할 수 있는 범위로 시험한다.
   - **비팔로워 도달 부족:** 대상이 알아볼 문제 또는 결과가 첫 화면에서 드러나게 한다. Trial Reels가 해당 계정에 있을 때만 선택적으로 제안한다.
   - **도달 대비 프로필 방문 부족:** 첫 화면의 약속을 본문에서 충족하는지, 그 주제가 목표 독자의 다음 문제로 이어지는지 확인한다.
   - **프로필 방문 대비 팔로우 부족:** 소개·고정 글·최근 피드가 같은 독자에게 같은 약속을 하는지 확인한다. 방문이나 팔로우 데이터가 없으면 가설로 표시한다.
3. **형식:** 릴스는 `구체적 결과·문제 → 과정/비교 → 답`, 캐러셀은 `표지의 한 가지 약속 → 둘째 장에서도 이해되는 단서 → 단계/사례 → 요약`. 릴스는 발견, 캐러셀은 이해·저장의 출발 가설일 뿐이다. 같은 주제로 시험하고, 플랫폼 가중치나 형식의 우위를 단정하지 않는다.
4. **4주 실험:** 1주 차에 기준선을 정하고 프로필과 대표 게시물을 점검한다. 2주 차에는 비교 가능한 게시물을 계획한다. 3주 차에는 훅·형식·설명 방식 가운데 하나만 바꾼다. 4주 차에는 관측 기간을 맞춰 비교한 뒤 유지·수정·중단을 결정한다. 우선순위마다 이번 주 행동 하나를 제안한다.
5. **측정:** 조회수와 고유 도달을 구분하고, 가능한 경우 비팔로워 도달·저장·공유·프로필 방문·계정 순증 팔로워를 같은 기간으로 기록한다. 게시물별 팔로우 귀속은 실제 인사이트에서 확인 가능할 때만 사용한다. 데이터가 없으면 주간 팔로워 수와 무엇을 시험했는지 기록한다. 적은 표본에서 관찰만으로 원인을 확정하지 않는다.

최근 사례가 필요하면 `flucto-media-research`의 현재 Flucto CLI 검색 절차로 자료를 갱신하고 자막·공개 설명·자기보고를 구분한다. 사례의 업로드 수와 시간대는 재현이 보장된 규칙이 아니다.

성장 전략과 초안 전용이다. 게시·댓글 전송·팔로우·DM·계정 설정 변경을 실행하지 않는다. 구매, 맞팔 품앗이, 대량 자동화 대신 관련 독자가 팔로우할 이유를 실험한다. 한서윤 Instagram 제작이나 실제 소통은 해당 전용 스킬이 담당한다.
