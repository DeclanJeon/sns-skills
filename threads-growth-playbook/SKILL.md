# Threads 팔로워 성장 플레이북

관심사가 맞는 사람에게 발견되고, 글과 답글에서 얻을 것이 분명해서 팔로우할 이유가 생기는 흐름을 설계한다.

1. **기준선.** 제공된 계정 주제, 타깃 독자, 운영 가능 시간, 최근 게시물과 지표를 확인한다. 모르는 수치는 미확인으로 둔다. 신규 계정은 데이터 없이 출발하며, 계획을 바꿀 정보만 질문한다.
2. **우선순위 3개.** [유튜브 근거와 적용 패턴](references/threads-growth-research.md)을 읽고 병목에 맞춰 순서를 정한다.
   - **신규:** 프로필에 독자와 얻을 것을 밝히고, 반복할 주제 하나를 정한다. 검색·커뮤니티에서 같은 관심사의 대화를 찾아 맥락 있는 답글을 남기고, 실제 독자 질문에 답하는 첫 글을 설계한다.
   - **정체:** 노출이 적으면 관련 대화에서의 발견과 첫 줄을, 노출은 있지만 대화가 적으면 경험의 구체성과 답할 자리를, 반응은 있지만 팔로워가 늘지 않으면 타깃 적합성과 다음 글을 기대할 이유를 먼저 점검한다. 이는 관측에 따른 가설이지 진단 확정이 아니다.
3. **글과 답글.** `구체적인 첫 줄 → 직접 경험이나 관찰 하나 → 필요하면 답할 수 있는 질문 하나`. 글은 단독으로도 가치가 있어야 한다. 답글에는 경험, 예외 또는 구체적 질문을 더하고, 반복되는 질문은 후속 글로 만든다. 두 형식을 비교할 때 주제는 유지한다.
4. **4주 실험.** 1주 차에는 기준선을 적고 주제·프로필을 정리한다. 2주 차에는 감당 가능한 글·답글 루틴을 실행 계획으로 정한다. 3주 차에는 변수 하나(예: 경험형 vs. 팁형)만 바꾼다. 4주 차에는 비교 후 유지·수정·중단할 것을 고른다. 우선순위별로 이번 주에 할 행동 하나씩 제안한다.
5. **측정.** 같은 기간의 노출, 다른 사람이 남긴 유효 답글(관련 경험·질문·반론), 계정 단위 순증 팔로워를 따로 기록한다. 프로필 방문은 확인 가능할 때만 추가한다. 데이터가 없으면 주간 팔로워 수와 실행 내역부터 기록하며 게시물별 팔로우나 인과를 추정하지 않는다.

자료에 제시된 시간·횟수·성장 속도·알고리즘 가중치는 보장이나 공식 규칙이 아니다. 최신 사례가 필요하면 `flucto-media-research`의 현재 Flucto CLI 검색 절차로 자료를 찾되 자막, 공개 설명, 자기보고를 구분한다.

성장 전략·초안 전용이다. 게시, 답글 전송, 팔로우, DM, 계정 수정은 실행하지 않는다. 팔로워 구매·스하리 품앗이·대량 자동화·분노 유발 대신 실제 대화를 제안한다. 한서윤 계정의 말투나 실제 운영이 요청되면 `han-seoyun-threads`가 담당한다.
